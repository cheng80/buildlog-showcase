## 3. 현재 작업

제작 준비 완료, **사이트 구현 전 일시 정지**. Next.js 16.3.5(App Router·TypeScript·ESLint, npm, Node 24.x) 프로젝트가 기본 템플릿 상태로 있다. 기획서 v1.2는 ‘이미 있는 프로덕트 홍보’ 톤이며, 사이트 문구는 humanize-korean으로 윤문하고 나열용 가운뎃점을 정리했다.

인포그래픽은 **사이트를 먼저 만든 뒤 실제 이미지 자리의 비율에 맞춰 다시 생성**하기로 했다(2026-09-16 결정). 진행 중이던 생성 작업은 모두 중단했다. `public/infographics/`에는 최신 문구·버튼 없음 상태의 `ig-003`·`ig-004`·`ig-006`·`ig-007`만 임시로 남아 있다.

## 6. 다음 작업

1. 기본 템플릿(`app/page.tsx`, `app/page.module.css`, `app/globals.css`, `app/layout.tsx`)을 소개 페이지로 교체한다. 헤더, 7개 섹션, 푸터를 기획서 4절 카피와 `FR-001`~`FR-004`, `BR-001`~`BR-006`대로 구현하고, 이미지 자리는 텍스트 카드(HTML/CSS)로 채운다. `S-04` 서비스 화면은 HTML/CSS 카드가 더 나은지 먼저 판단한다.
2. `npm run lint`, `npm run typecheck`, `npm run build`를 실행하고 360·390·768·1440px, 키보드, 앵커, FAQ를 브라우저로 확인한다.
3. 섹션별로 이미지가 실제로 필요한 자리와 비율(데스크톱·모바일)을 표로 정리한다.
4. 그 비율에 맞춰 해당 `IG-xxx` 프롬프트를 고치고(분할·재구성 포함) `scripts/gen-infographic.sh`로 생성, 검수 후 `next/image`로 연결한다.
5. 결과를 9절 검증 표와 이 문서에 기록한다.

## 7. 인수인계

**완료:** 기획 문서 v1.2, 사이트 문구 윤문, Next.js 기본 프로젝트, Codex 인포그래픽 생성 스크립트, 임시 인포그래픽 4장. 세션 재개용 요약은 상위 폴더의 `../HANDOFF.md`에 있다.

**현재 맥락:** 개인·인디 개발자와 소규모 개발팀·개발사가 개발 기록을 프로젝트별로 모아 알리는 서비스를 40일 동안 만들 계획이며, 지금 필요한 것은 이를 소개하는 홈페이지다. 개발 기간은 내부 계획일 뿐이고, 사이트는 이미 있는 프로덕트를 홍보하는 톤으로 만든다(`BR-001`). 본 서비스의 상세 기획은 별도로 만들 예정이다.

**유지할 경계:** 이 묶음에서 실제 서비스의 회원·피드 게시·결제·지도·DB·API를 설계하거나 구현 범위로 추가하지 않는다. `WF-006`은 홍보용 삽화다. 예시를 실사용 자료로 표시하지 않는다.

**바로 할 일:** 6절 1번(사이트 구현)부터. 인포그래픽 재생성은 사이트 구현과 이미지 자리 정리 뒤에 한다. 자료가 없는 부분은 명시된 기본값과 생략 규칙을 사용한다.

**검증:** 문서와 실제 사이트 검증을 분리해 9절을 확인한다. 사이트 검증 결과는 아직 없다.

## 8. 변경된 계약

신규 문서이므로 기존 코드/API 계약 변경은 없다. 원본의 파일 역할·ID 체계·검증 상태 체계를 사용했다. 원본 ZIP의 평면 배치를 README 권장 구조로 정리했고, 필요 없는 빈 계획·결정 템플릿을 제외했다.

v1.2: 사이트 톤을 이미 있는 프로덕트 홍보로 변경. `S-05`는 `#journey`(40일 제작 방향) → `#start`(시작하기 3단계), 헤더 링크는 ‘소개 / 화면 / 시작하기’, 주 CTA는 ‘화면 둘러보기’, FAQ는 서비스 이용 질문으로 교체.

v1.1: 소개 사이트 프레임워크를 Next.js App Router·TypeScript로, 배포 플랫폼을 Vercel로 정했다. 기존 단일 페이지·정적 콘텐츠 범위와 실제 서비스 기획의 분리는 유지한다. 아직 코드와 원격 배포 상태 변경은 없다.
